# Acknowledgements

This work builds on the following open-source projects and datasets. Their code
and data are not vendored in this repository; the setup instructions fetch the
pinned PHP-FL repository locally.

- **PHP-FL** — the official implementation of “A Fair Federated Learning Method
  for Handling Client Participation Probability Inconsistencies in Heterogeneous
  Environments” (NeurIPS 2025).  
  https://github.com/Siyuan01/PHP-FL-main
- **FedAPEN** — the official implementation of “FedAPEN: Personalized Cross-silo
  Federated Learning with Adaptability to Statistical Heterogeneity” (KDD 2023).  
  https://github.com/zhenqincn/FedAPEN
- **CIFAR-10** — the dataset used for the half-scale experiments.  
  https://www.cs.toronto.edu/~kriz/cifar.html
- **PyTorch / torchvision** — model training and vision utilities.
- **scikit-learn, SciPy, pandas, NumPy, Matplotlib, seaborn** — analysis and
  figures.

The diagnostic ladder and two-axis analysis are original to this repository.
The underlying federated-learning methods remain the work of their respective
authors.
