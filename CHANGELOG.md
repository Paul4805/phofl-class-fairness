# Changelog

All notable changes to this repository are recorded here. The project follows
semantic versioning for releases.

## [0.1.0] - 2026-11-08

### Added

- Measurement paper: client-FM versus two-axis (client × class) fairness.
- CIFAR-10 half-scale runs for PHP-FL, FedAPEN, and Standalone.
- Support-aware client × class analysis, AM-normalized gap analysis, and
  ranking-disagreement tables.
- Diagnostic ladder: class-balanced rehearsal, confusion-targeted loss,
  worst-class-weighted aggregation, and per-class distillation.
- Negative-result summary (`phofl_method/LADDER_SUMMARY.md`).
- Resumable A/B/C experiment notebook and runtime harness.
- Public-repository metadata: license, citation, contribution guide, security
  policy, code of conduct, issue/PR templates, and CI smoke tests.

### Notes

- No method contribution is claimed.
- Large checkpoints, generated datasets, and third-party clones are excluded.
